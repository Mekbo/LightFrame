全局设置

个人加工参数保存在服务端 config/users/<账户ID>.json；产物按「账户ID / 时间戳」分目录保存，账户 ID 不可变，改名不会丢历史。「批量删除」会删除勾选任务的产物文件（需确认）；「批量清除」仅移除任务记录、保留文件。
目录名均为相对路径，位于「我的空间 / <账户>」之下。输出目录名可在全局设置或我的空间中修改（两处自动同步，磁盘目录原地改名）；产物输出路径由系统自动填写，任何用户（含管理员）不可修改。
控制「我的空间」上传与浏览限制：单次上传的文件数量与总大小、目录列表默认每页条数。调整后立即生效，无需重启。
新建账户的「我的空间」默认大小（管理员 50G、普通用户 10G）。调整只影响之后新建的账户；已有账户请在「用户管理 → 配额」中单独修改。未单独设置过配额的账户会跟随此默认值。
全局同时执行 2 个任务（图片 / 视频 / Live 通用）；本机与在线用户共用此设置，超出的任务按提交顺序先进先出排队，有任务完成即自动补位，任务管理里可看「我的排队数 / 前面有 xx 位排队」。两项均可手动调节，且并发数不会超过最高限制；保存后即时生效，无需重启。
图片 / 视频创作完成后，「在线预览」随机展示的成品样例数量；默认 1 个，可在 1–6 之间调节，保存后即时生效。
同一段素材在「跨任务」中被复用超过「复用上限 K」时，会判定原创度不达标并拦截任务（默认 K=2，即第 2 次使用起算复用）。正式使用可保持开启防刷；反复用同一批素材做测试时，可临时关闭或调高 K，避免每次都被拦截。

3各场景操作要点 点开查看详细步骤，默认收起，页面更清爽
🖼️ 图片处理：批量加工怎么跑
  1. 在「图片处理」分组选择功能（格式转换 / 裁切 / 缩放 / 去水印 / 图片加文字 / Live 图提取）。
  2. 打开面板顶部开关，设置对应参数；多个开关同时打开时，一次任务会按顺序依次处理。
  3. 「图片加文字」可选择模板中心里的图片模板，也可填入自定义文案，支持 AI 生成文案。
  4. 在执行区用「＋ 从文件添加」或「＋ 从目录添加」上传素材，点「开始图片批处理」。
  5. 刷新页面会回到上次操作的位置；退出账户重新登录后才默认回到任务管理。
🧺 文案生产：从选题到打包
  1. ① 选题搭建：填写或 AI 生成选题、卖点与受众。
  2. ② 脚本创作：按场景生成脚本，可套用模板中心的 AI 提示词模板。
  3. ③ 配音生成：选择配音模型与角色，试听并生成音频。
  4. ④ 封面制作：选封面模板、填标题文案并生成封面图。
  5. ⑤ 打包文案：勾选需要的脚本（支持一键全选 / 全不选）打包下载，下载过程有进度提示。
🎬 视频创作：九步向导
  1. ① 添加素材 → ② 添加封面 → ③ 配音 + 字幕（脚本）。
  2. ④ 视频模板：选模板决定底部字幕与顶部标题的位置、字号、颜色与描边；模板在「模板中心」统一管理。
  3. ⑤ 背景乐 → ⑥ 视频时长 → ⑦ 转场效果 → ⑧ 画面填充 / 片头兜底。
  4. ⑨ 原创度检验与提交：同一批素材跨任务复用超上限会被拦截，测试时可临时调高上限或关闭校验。
🗂️ 模板中心：一处维护，处处可用
  • 模板中心是全应用唯一数据源，分「图片模板 / 视频模板 / AI 提示词模板」三类。
  • 在模板中心创建、修改、删除、共享；各工作场景里的「＋ 存为模板 / ✎ 修改」也会统一保存回这里。
  • 共享标识：🤝 已共享（我共享出去的）、🔒 他人共享（别人共享给我，只读）、🌐 公共模板（系统预置）。
  • 点模板名称、左侧缩略图或「👁 预览」可查看效果：图片 / 视频渲染真实效果图，AI 提示词可试填 {} 块并实时看最终提示词；预览只读，不会改动模板。
  • 工作场景的模板下拉只负责选择，删除请到模板中心操作。
📁 我的空间：素材仓库与产物归档
  • 登录后每个账户拥有独立空间（管理员默认 50G、普通用户 10G，管理员可在「用户管理」随时调整配额），页面右上角实时显示用量；点开「我的空间」直接进入空间根目录。
  • 系统自动创建作品根目录（默认「全部作品」）及其下的图片 / 视频输出子目录 OutPut_Image / OutPut_Video，所有加工产物统一落在作品根下；作品根为系统保留目录，任何用户（含管理员）不可改名 / 删除。两个输出子目录名可在「全局设置」或「我的空间」中修改（两处自动同步，磁盘目录原地改名，旧产物保留）；产物路径由系统自动填写，不可自定义。
  • 可在空间根目录自建素材目录（最多两层）存放预处理素材，支持图片、视频、文档等格式；空间根目录不允许直接上传文件，请先进入或新建子目录。
  • 上传支持批量：单次最多 10 个文件、总大小 ≤200M，两项限制都可在「全局设置 → 我的空间上传限制」中调整。
  • 文件管理支持重命名、移动到其它目录、单独 / 批量删除；图片视频可点击在线预览（图片支持滚轮缩放），目录列表默认每页 10 条（可选 10/20/50）。
  • 素材添加按访问来源自动切换：通过 localhost / 127.0.0.1 在服务器本机登录的用户（含管理员）按钮保持「从文件 / 从目录添加」，直接读本机磁盘；用局域网 IP 或其它电脑访问的在线用户按钮自动变为「从空间文件 / 从空间目录添加」，点击弹出空间选择器（均支持全选 / 反选），需先把素材上传到「我的空间」。无论哪种方式，图片 / 视频产物始终保存在「我的空间 / 作品根 / 输出目录」中。
  • 空间不足时页面会提醒清理素材或产物；删除产物请到任务管理或我的空间中操作。
🤖 AI 大模型与账户权限
  • 在「系统设置 → AI 大模型」添加模型并填写密钥；密钥只存服务端，前端不回显明文。
  • 管理员与普通用户规则一致：只加载「自己创建的」+「别人显式共享且启用的」模型；任何登录用户都能共享 / 取消共享自己的模型。
  • 账户分管理员 / 普通用户 / 游客三级；全局项（并发、输出目录、更新周期等）由管理员维护，普通用户保存自己的加工参数。
📋 任务管理、产物与备份
  • 顶部仪表盘显示完成率、四态数量与分布进度条，点卡片即可筛选对应状态的任务。
  • 任务与产物按「账户 ID / 时间戳」分目录，输出根目录在「全局设置」里配置，图片与视频目录相互独立。
  • 「批量删除」会删除勾选任务的产物文件（需确认）；「批量清除」只移除任务记录、保留文件。
  • 建议定期备份 config 目录（账户、配置、模板、任务记录）与产物输出目录。
4系统更新方法 检查周期、状态与版本确认
  1. 打开「系统设置 → 全局设置」，在「系统更新检查周期」里选择 每 1 周（默认）、每 1 个月 或 不检查，选择后立即生效。
  2. 应用会按所选周期在后台自动核对版本；也可以随时进入「关于应用 → 系统更新」，点「立即检查更新」手动核对一次。
  3. 「系统更新」页显示当前版本号、版本状态、最新版本、上次 / 下次检查时间与功能更新日志；检测到新版本时，左侧「系统更新」菜单会出现红色气泡，页面也会给出新版本号与本次更新内容。
  4. 请由应用维护者依照发布说明完成版本升级；升级前建议先备份 config 目录与产物输出目录，升级完成后刷新页面，并在「系统更新」页确认当前版本号已更新。
  5. 选择「不检查」时不会自动联网核对，但「立即检查更新」仍可手动使用；网络不可用时会提示「暂未获取到发布信息」，不影响任何现有功能。
说明：本页只说明版本检查与确认方式，不涉及任何安装环节；版本升级由应用维护者按发布说明完成。需要查看当前版本状态与更新日志，请点左侧「关于应用 → 系统更新」。
